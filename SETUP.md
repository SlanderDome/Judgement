# Judgement Online Setup

This project is a Node.js monorepo with a server and client.

## What you need

- Node.js 18+ installed
- npm (comes with Node.js)
- Git, if you are cloning the repo

## Get the project

### Option 1: Clone from Git

```bash
git clone https://github.com/SlanderDome/Judgement
cd Judgement
```

### Option 2: Copy the folder

- Copy the full `Judgement` folder to the new PC.
- Open a terminal in that folder.

## Install dependencies

```bash
npm install
```

## Run the app

Open two terminals from the project root:

```bash
npm run dev:server
```

```bash
npm run dev:client
```

## Ports

- Server: `http://localhost:3001`
- Client: `http://localhost:3000`

## Useful commands

```bash
npm run start:server
```

```bash
npm run build:client
```
